# React & TypeScript Interactive UI Component Library

An interactive UI debugging suite built with **React**, **TypeScript**, and **HTML5 Canvas / SVG**. Designed to visualize data structures, track state variations, and provide deterministic, pass/fail visual verification criteria for frontend components.

## Features
- **TypeScript & React State Management:** Strict type safety and custom hooks for component rendering.
- **Canvas / SVG Rendering:** Custom SVG dynamic graph rendering and interactive canvas element isolation.
- **Visual Debugger Workflow:** Built-in verification controls to isolate layout regressions and document step-by-step bug reproduction.

## Setup & Running Locally
```bash
git clone [https://github.com/mutavefaith/react-ui-canvas-debugger.git](https://github.com/mutavefaith/react-ui-canvas-debugger.git)
cd react-ui-canvas-debugger
npm install
npm run dev
